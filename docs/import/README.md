# Imported project artifacts

This directory documents the migration of existing MR עדולם project artifacts into GitHub.

The import was intentionally non-destructive:
- readable source and documentation were committed;
- DOCX documentation was converted to Markdown for diff-friendly version control;
- binary originals are listed in `PROJECT_LIBRARY_MANIFEST.md` and remain preserved in the Project Library until exact byte transfer is available.

No binary asset was silently replaced, recompressed, or renamed as though it were the original.
