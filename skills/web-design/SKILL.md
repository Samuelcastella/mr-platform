# SKILL — WEB DESIGN
## MR Adulam / עדולם

### 1. Propósito
Diseñar sitios web profesionales, escalables y orientados a negocio, transformando la estrategia de marca en experiencias web coherentes, modernas, accesibles y preparadas para implementación.

### 2. Alcance
Esta skill cubre:
- Arquitectura visual de sitios web.
- Diseño responsive para móvil, tablet y desktop.
- Sistemas de diseño y componentes reutilizables.
- Layouts, grids, spacing y jerarquía visual.
- Tipografía, color, contraste y composición.
- Navegación, menús y estructura de páginas.
- Hero sections y landing pages.
- Catálogos y fichas de producto.
- E-commerce.
- Estados de interfaz: hover, active, loading, empty y error.
- Accesibilidad web.
- SEO visual y estructura semántica.
- Conversión y llamados a la acción.
- Microinteracciones y animaciones.
- Performance desde la perspectiva del diseño.
- Preparación del diseño para implementación en código.
- Consistencia visual entre páginas.
- Escalabilidad del sistema visual.

### 3. Principio central de MR Adulam
La web de MR Adulam / עדולם no debe construirse como una página limitada a una sola categoría, especialmente ropa.

Debe funcionar como la plataforma digital de una marca amplia y escalable, capaz de incorporar nuevas categorías, colecciones, productos y líneas de negocio sin tener que reconstruir su identidad visual.

### 5. Reglas de diseño
1. Mobile-first cuando el contexto lo favorezca.
2. Diseñar con sistema, no con páginas aisladas.
3. Priorizar claridad y jerarquía visual.
4. Mantener consistencia entre componentes.
5. Diseñar estados completos, no solamente el estado ideal.
6. Considerar accesibilidad desde el inicio.
7. Evitar tendencias visuales que perjudiquen usabilidad o conversión.
8. Mantener la identidad de MR Adulam / עדולם independiente de una categoría concreta.
9. Diseñar pensando en crecimiento futuro.
10. Preparar especificaciones suficientemente claras para que otro desarrollador pueda implementar el diseño.

### 6. Responsive Design
Cada diseño debe considerar como mínimo:
- Móvil.
- Tablet.
- Desktop.

Se deben definir:
- Breakpoints.
- Comportamiento del layout.
- Escalado tipográfico.
- Espaciado.
- Reordenamiento de componentes.
- Navegación móvil.
- Imágenes responsive.
- Controles táctiles.

### 7. Sistema visual
Definir y mantener:
- Design tokens.
- Colores.
- Tipografía.
- Escala de tamaños.
- Espaciado.
- Bordes.
- Radios.
- Sombras.
- Iconografía.
- Componentes.
- Estados.
- Reglas de composición.

### 8. E-commerce y catálogo
Cuando el proyecto lo requiera, diseñar:
- Página principal.
- Categorías.
- Colecciones.
- Catálogo.
- Filtros.
- Búsqueda.
- Ficha de producto.
- Variantes.
- Carrito.
- Checkout.
- Cuenta del cliente.
- Confirmaciones.
- Estados sin resultados.
- Productos agotados.
- Productos nuevos y destacados.

### 9. Conversión
Cada página debe tener un objetivo claro.

Considerar:
- CTA principal.
- CTA secundarios.
- Jerarquía de contenido.
- Confianza.
- Prueba social cuando corresponda.
- Reducción de fricción.
- Claridad de precios y condiciones.
- Flujo hacia la acción principal.

### 10. Accesibilidad
Considerar:
- Contraste.
- Tamaños legibles.
- Estados visibles.
- Navegación por teclado.
- Jerarquía semántica.
- Etiquetas y nombres accesibles.
- Áreas táctiles adecuadas.
- No depender exclusivamente del color.

### 12. Criterio de calidad
Un diseño Web Design para MR Adulam debe ser:

Profesional + claro + escalable + responsive + accesible + consistente + orientado a negocio.

### 13. Regla de integración
No crear soluciones visuales aisladas si existe un sistema reutilizable.

Antes de diseñar una nueva página o componente, comprobar:
1. Si ya existe un patrón.
2. Si el nuevo elemento puede reutilizarse.
3. Si necesita convertirse en componente.
4. Si afecta al sistema visual.
5. Si funciona en móvil, tablet y desktop.

### 14. Identidad de marca
El nombre oficial de la marca es:

MR Adulam

Representación hebrea:

עדולם

No utilizar slogans o estructuras que limiten la marca a un solo nicho o categoría.

### 15. Principio de escalabilidad
Toda decisión de diseño debe evaluarse también desde la perspectiva de crecimiento:

¿Funcionará cuando MR Adulam tenga más productos, más categorías, más páginas, más clientes y nuevos mercados?

Si la respuesta es no, debe replantearse la solución.
